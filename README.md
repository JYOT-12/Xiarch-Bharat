# Autonomous Agentic AI System (Intern Take-Home Assignment)

A lightweight, robust, and modular agentic AI system built in Python that takes a high-level natural language goal, dynamically plans steps, utilizes live tools (Web Search & Local File Writer), handles runtime errors via self-correction, and generates a structured Markdown report.

---

## Features
- **Dynamic Goal Decomposition:** Uses an LLM planner to break goals down into structured sequential steps.
- **Live Tool Integration:** Leverages DuckDuckGo for real-time web data extraction (no curated datasets required).
- **Graceful Error Handling & Self-Correction:** Detects weak/failed tool returns and automatically triggers recovery routines with fallback queries.
- **Structured Output:** Automatically compiles findings into a clean, formatted Markdown report.
